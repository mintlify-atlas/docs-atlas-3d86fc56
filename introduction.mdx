Welcome to the documentation for **IT10.1**, a set of first-term Information Technology coursework exercises focused on beginner Java programming and introductory database concepts.

Each folder in the repository is a self-contained Java project targeting one specific concept. Open any individual project in NetBeans, run it, and study the focused example.

## What this repo covers

| Topic | Projects |
|---|---|
| Variables & data types | `DataTypes`, `CharacterBuilding`, `ChangeIsGood` |
| Escape sequences & output | `escapesequences`, `DataTypes` |
| Arithmetic & modulus | `JavaMaths`, `IveGotThePower` |
| Math class methods | `HighsAndLows`, `Armathgeddon`, `RealAltitude`, `SeeYouRound` |
| Random numbers | `RandomGenerator`, `RandomPractice`, `DiceRoller`, `SomethingRandom` |
| Geometry calculations | `Aftermath`, `FullCircle`, `NobodyPutsPythagorusInACorner` |
| GUI dialogs | `MessageDialogs`, `UserInput_`, `LoginCheck` |
| Assessments | `Tests/Glasby_Nathan_JavaTest1`, `Tests/Glasby_Nathan_Term1`, `Tests/Glasby_Nathan_Term1_v2` |
| Databases | `!Databases/BaggageDB.mdb` |

<Note>
There is no single application entry point for the whole repository. Each folder is intended to be opened and run individually.
</Note>
