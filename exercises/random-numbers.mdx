`Math.random()` returns a random `double` in the range **0.0 (inclusive) to 1.0 (exclusive)** every time it is called. On its own that range is not very useful, but with simple arithmetic you can scale it to any range you need.

## The raw value

**RandomGenerator** calls `Math.random()` once to show the raw output:

```java
System.out.println(Math.random());
```

Sample output:
```
0.7342918462193847
```

Each run produces a completely different value. Run the program multiple times to see this.

## Scaling to a range

The general formula for producing a random integer in a given range is:

```java
(int)(Math.random() * range) + startingValue
```

- **`range`** is the number of possible values (size of the window).
- **`startingValue`** shifts the window to start at the right number.
- The cast `(int)` truncates the decimal, giving a whole number.

**RandomPractice** works through a series of examples that build intuition for this formula:

```java
// 0.0 to 0.99...
System.out.println(Math.random());

// 1.0 to 9.99...  (decimal, not cast to int)
System.out.println(Math.random() * 9 + 1);

// 0 to 5  (6 possible values: 0,1,2,3,4,5)
System.out.println((int)(Math.random() * 6));

// 1 to 10
System.out.println((int)(Math.random() * 10) + 1);

// 4 to 9  (6 possible values starting at 4)
System.out.println((int)(Math.random() * 6) + 4);

// -10 to -1  (10 possible values, shifted by -10)
System.out.println((int)(Math.random() * 10) - 10);

// -1 to 1  (3 possible values: -1, 0, 1)
System.out.println((int)(Math.random() * 3) - 1);

// 120 to 150  (31 possible values starting at 120)
System.out.println((int)(Math.random() * 31) + 120);
```

<Tip>
**How to calculate `range`:** subtract the smallest value from the largest, then add 1.
For 4 to 9: `(9 - 4) + 1 = 6`, so use `Math.random() * 6`.
</Tip>

## Dice roller

Rolling a six-sided die means producing a random integer from 1 to 6. **DiceRoller** rolls two dice and sums them:

```java
int die1 = (int)(Math.random() * 6) + 1;
int die2 = (int)(Math.random() * 6) + 1;

int total = die1 + die2;

System.out.println("First die rolled a " + die1 + ".");
System.out.println("Second die rolled a " + die2 + ".");
System.out.println("Total roll is " + total + ".");
```

- `Math.random() * 6` gives a value from `0.0` to `5.999...`
- Casting to `int` gives `0`, `1`, `2`, `3`, `4`, or `5`
- Adding `1` shifts the range to `1`–`6`

## Generating a random PIN

Each digit of a PIN is an independent integer from 0 to 9. **Armathgeddon** prints a four-digit PIN one digit at a time:

```java
System.out.println("The pin code for your new bank card is ");
System.out.print((int)(Math.random() * 10) + 0);
System.out.print((int)(Math.random() * 10) + 0);
System.out.print((int)(Math.random() * 10) + 0);
System.out.print((int)(Math.random() * 10) + 0);
System.out.print(".");
```

`Math.random() * 10` produces a value from `0.0` to `9.999...`, which casts to one of `0`–`9`.

## Loops with random values

**SomethingRandom** combines a loop with random output, and also builds a random phone number digit by digit:

```java
for (int i = 0; i < 10; i++) {
    System.out.println((int)(Math.random() * 3));
}
```

The phone number generation prints each part separately using `System.out.print` (no newline) so all the digits appear on one line:

```java
// Format: 0XX XXX XXXX
System.out.print("0");
System.out.print((int)(Math.random() * 10));
System.out.print((int)(Math.random() * 10));
System.out.print(" ");
System.out.print((int)(Math.random() * 10));
System.out.print((int)(Math.random() * 10));
System.out.print((int)(Math.random() * 10));
System.out.print((int)(Math.random() * 10));
System.out.print(" ");
System.out.print((int)(Math.random() * 10));
System.out.print((int)(Math.random() * 10));
System.out.print((int)(Math.random() * 10));
System.out.print((int)(Math.random() * 10));
System.out.println("");
```

<Note>
`System.out.print` outputs text without moving to the next line. `System.out.println` outputs text and then moves to the next line. Use `print` when you want to build up a line piece by piece.
</Note>

## Range formula summary

| Target range | Formula |
|---|---|
| `0.0` to `< 1.0` | `Math.random()` |
| `0` to `n-1` | `(int)(Math.random() * n)` |
| `1` to `n` | `(int)(Math.random() * n) + 1` |
| `a` to `b` (inclusive) | `(int)(Math.random() * (b - a + 1)) + a` |
| Single digit `0`–`9` | `(int)(Math.random() * 10)` |
| Die face `1`–`6` | `(int)(Math.random() * 6) + 1` |
